# HANZALA FORTRESS — install files

An encrypted on-device vault for journalists' files and photos. Everything stays encrypted on your own device. No account, no login.

This page holds install files only.

## iPhone

Join the beta on TestFlight: https://testflight.apple.com/join/t1dbYhd5

## Android

1. Download [hanzala-fortress.apk](https://github.com/hanzalaca/hanzala-fortress-downloads/releases/latest/download/hanzala-fortress.apk) on your phone.
2. Open it. If the phone asks, allow installing apps from this source (your browser or file manager), then go back and tap Install.
3. Later updates install over this version and keep your vault. Do not uninstall the app to update.

## Mac

1. Download [HANZALA-FORTRESS-mac.dmg](https://github.com/hanzalaca/hanzala-fortress-downloads/releases/latest/download/HANZALA-FORTRESS-mac.dmg).
2. Open it and drag the app to Applications.
3. Apple silicon Macs only (M1 or later).
