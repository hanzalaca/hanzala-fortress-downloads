# Owner's standing instruction: do it yourself first

The owner wants Claude to carry out every step itself, in every HANZALA project, instead of
handing the owner instructions. The owner has given standing permission for this.

- First choice: do it yourself with whatever this session can reach: repository and GitHub tools,
  the connected Cloudflare account, a computer folder shared through Remote Control, or screen and
  app control on the owner's Mac when the session runs in the Claude desktop app.
- Ask the owner only for what no tool can reach (a login or password, a payment, a decision that is
  only theirs). Then give one exact, minimal step with the direct link, and continue the rest yourself.
- Before anything that deletes or cannot be undone, say exactly what will be removed and what will
  stay (for example: "only the branch `develop`, not the repository"), because the owner acts on it as written.
